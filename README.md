# 🎯 AI-Агент для поиска работы (SuperJob Pro Edition)

Интеллектуальный агент для глубокого анализа вакансий, расчетного скоринга, автоматизации качественных откликов (3–5 в неделю), ведения CRM-воронки и комплексной подготовки к интервью.

> 📚 **База знаний**: Архитектура агента и логика отбора построены на экспертных рекомендациях портала работодателей и рекрутеров [SuperJob Pro](https://www.superjob.ru/pro/).

## 🌟 Ключевые возможности

### 1. Глубокий парсер вакансий
- Автоматически определяет источник ссылки:
  - **hh.ru**: обращается к открытому REST API `api.hh.ru/vacancies/{id}`, скачивая полный стек ключевых навыков, вилку зарплат, график и чистое описание.
  - **superjob.ru**: специализированный парсер страниц вакансий.
  - **Текст в чате / файле**: извлечение структурированной сущности `ParsedJob`.

### 2. Экспертный скоринг по SuperJob Pro
- Оценка соответствия кандидата и привлекательности роли по 5 шкалам:
  - **Hard Skills Match** (до 40 баллов)
  - **Experience & Grade Match** (до 25 баллов)
  - **Education & Domain Match** (до 15 баллов: СПО МТИ, «Информационные системы»)
  - **Conditions & Transparency** (до 10 баллов: удаленка, вилка)
  - **Red Flags Penalties** (от 0 до -25 баллов): размытые требования, «10 ролей в одном», токсичные формулировки («24/7», «ненормированный график»).
- Итоговая карточка: **Балл (0-100)**, **Плюсы**, **Риски / Red Flags**, **Пробелы в стеке (Gaps)** и **Стратегия отклика**.

### 3. Генерация откликов под вакансию (SuperJob Pro standard)
- **Правило первых 2 строк (Hook)**: рекрутер сканирует отклик за 5-10 секунд. Первые две строки сразу закрывают ключевой фильтр вакансии.
- **Два формата отклика**:
  - ⚡ *Краткий отклик* (500–750 символов) — для формы hh.ru / SuperJob.
  - ✉️ *Развернутое письмо* (800–1100 символов) — для прямого письма HR/тимлиду на email или в Telegram.
- **Фактологические пруфы**: только реальные проекты ([gorizont-blog.ru](https://gorizont-blog.ru), `clinic_connect`, `AI Blog Generator`).
- **Строгий запрет клише**: никаких «легко обучаемый», «стрессоустойчивый».

### 4. Подготовка к интервью в 3 блока (SuperJob Pro)
1. **Блок 1: Технический скрининг** — 10 точечных вопросов по стеку вакансии с готовыми тезисами.
2. **Блок 2: HR и поведенческие вопросы (STAR-модель)**:
   - Самопрезентация (Elevator Pitch на 90 секунд).
   - «Почему именно наша компания?».
   - Кейс сложного бага/задачи по STAR (*Situation, Task, Action, Result*).
   - Аргументация зарплатных ожиданий для джуниора по методологии SuperJob Pro.
3. **Блок 3: Вопросы работодателю** — 3–5 зрелых вопросов, повышающих конверсию в оффер.

## 🛠 Быстрый старт

### 1. Установка
```bash
pip install -r requirements.txt
```

### 2. Настройка `.env`
Скопируйте пример:
```bash
cp .env.example .env
```
Заполните параметры:
- `BOT_TOKEN`: токен из [@BotFather](https://t.me/BotFather) в Telegram.
- `ALLOWED_USER_IDS`: ваш числовой Telegram ID (узнать в [@userinfobot](https://t.me/userinfobot)).
- **Выбор LLM (OpenAI Chat GPT или Google Gemini)**:
  - **Для OpenAI Chat GPT**:
    ```env
    LLM_PROVIDER=openai
    OPENAI_API_KEY=sk-...ваш-ключ-openai...
    OPENAI_MODEL=gpt-4o-mini
    OPENAI_BASE_URL=https://api.openai.com/v1
    ```
    *(Поддерживаются любые OpenAI-совместимые шлюзы: прямой api.openai.com, OpenRouter, ProxyAPI, VseGPT, DeepSeek и др.)*
  - **Для Google Gemini (альтернатива)**:
    ```env
    LLM_PROVIDER=gemini
    GEMINI_API_KEY=ваш-ключ-gemini
    GEMINI_MODEL=gemini-2.5-flash
    ```

### 3. Запуск Telegram-бота
```bash
python -m bot.main
```

## 💻 Использование через консоль (CLI)

```bash
# 1. Глубокий парсинг вакансии (по URL или файлу)
python cli.py parse "https://hh.ru/vacancy/123456"

# 2. Скоринг вакансии и рисков (SuperJob Pro)
python cli.py score "data/sample_vacancy.txt"

# 3. Краткий отклик для чата
python cli.py cover "data/sample_vacancy.txt"

# 4. Развернутое письмо для HR
python cli.py cover "data/sample_vacancy.txt" --detailed

# 5. 3-блочная подготовка к интервью (STAR + Tech)
python cli.py interview "data/sample_vacancy.txt"

# 6. Разбор вопросов после собеседования (Interview Debrief)
python cli.py debrief "Спросили про уровни изоляции в PostgreSQL и MVCC"

# 7. Просмотр текущей воронки CRM
python cli.py stats
```
