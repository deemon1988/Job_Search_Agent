# 📊 Пошаговая инструкция: Настройка интеграции с Google Sheets

Интеграция с Google Таблицами позволяет автоматически синхронизировать каждый отклик на вакансию из Telegram-бота или CLI прямо в вашу Google Таблицу, доступную со смартфона и ПК.

---

## Шаг 1. Создание проекта в Google Cloud Console
1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/).
2. Войдите под своим Google-аккаунтом.
3. В левом верхнем углу нажмите на выбор проекта ➔ **New Project (Новый проект)**.
4. Назовите проект (например: `Job-Search-Agent`) и нажмите **Create**.

---

## Шаг 2. Включение необходимых API
В созданном проекте необходимо включить 2 API:
1. Перейдите в меню ➔ **APIs & Services** ➔ **Library** (Библиотека).
2. Найдите в поиске **Google Sheets API** ➔ нажмите **Enable (Включить)**.
3. Вернитесь в Library, найдите **Google Drive API** ➔ нажмите **Enable (Включить)**.

---

## Шаг 3. Создание Сервисного Аккаунта (Service Account)
1. В меню выберите **IAM & Admin** ➔ **Service Accounts (Сервисные аккаунты)**.
2. Нажмите **+ CREATE SERVICE ACCOUNT** (Создать сервисный аккаунт).
3. Введите название (например: `job-agent-sheets`).
4. Нажмите **Create and Continue**, затем **Done** (роли назначать не обязательно).

---

## Шаг 4. Скачивание ключа `credentials.json`
1. В списке сервисных аккаунтов нажмите на созданный аккаунт (нажмите на его email).
2. Перейдите во вкладку **Keys (Ключи)**.
3. Нажмите **Add Key (Добавить ключ)** ➔ **Create new key (Создать новый ключ)**.
4. Выберите тип **JSON** и нажмите **Create**.
5. Файл ключа скачается на ваш компьютер.
6. **Скопируйте этот файл в папку проекта** `Job_Search_Agent` и переименуйте его строго в:
   ```
   credentials.json
   ```
7. Откройте скачанный файл блокнотом и найдите строку `"client_email"`:
   *(Она выглядит так: `job-agent-sheets@job-search-agent-12345.iam.gserviceaccount.com`)*. **Скопируйте этот email!**

---

## Шаг 5. Создание Google Таблицы и выдача прав
1. Перейдите в [Google Таблицы](https://sheets.google.com) и создайте новую пустую таблицу.
2. Назовите таблицу, например:
   ```
   Job_Search_CRM
   ```
3. Нажмите кнопку **«Настройки доступа» / «Поделиться» (Share)** в правом верхнем углу.
4. В поле «Добавьте пользователей или группы» вставьте скопированный **email сервисного аккаунта** (`client_email` из шага 4).
5. Убедитесь, что выбрана роль **«Редактор» (Editor)**.
6. Снимите галочку «Уведомить пользователей» и нажмите **«Предоставить общий доступ» / «Отправить»**.

---

## Шаг 6. Настройка файла `.env`
В файле `.env` в корне проекта проверьте строки:
```env
# Имя файла ключа (лежит в корне проекта)
GOOGLE_SHEETS_CREDENTIALS_FILE=credentials.json

# Название вашей таблицы (или ее ID из адресной строки)
GOOGLE_SHEET_NAME_OR_ID=Job_Search_CRM
```

> 💡 **Совет**: Если вы переименуете таблицу или хотите использовать точную привязку, можно указать вместо названия её **ID из ссылки** браузера:
> `https://docs.google.com/spreadsheets/d/`**`1BxiMVs0XR_XXXXX_YYYYY`**`/edit` ➔ `GOOGLE_SHEET_NAME_OR_ID=1BxiMVs0XR_XXXXX_YYYYY`

---

## Шаг 7. Проверка работы
Запустите команду проверки через CLI или сохраните отклик в Telegram-боте:
- Агент автоматически подключится к таблице.
- Если таблица пустая, он сам создаст красивую шапку:
  `ID`, `Дата отклика`, `Платформа`, `Компания`, `Вакансия`, `Ссылка`, `Вектор резюме`, `Статус`, `Дедлайн тестового`, `Сопроводительное письмо`, `Заметки`.
- При каждом нажатии кнопки **«💾 Сохранить в CRM»** в боте строка мгновенно появится в вашей таблице!
